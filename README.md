# 💼 Online Job Portal System

> A web-based application designed to bridge the gap between job seekers and employers by offering an intuitive platform for job listings, applications, and recruitment management.

---

## 📌 Overview

The **Online Job Portal System** is a full-stack web application that simplifies the hiring process. It allows **employers** to post job openings, and **job seekers** to search and apply for jobs based on their qualifications and interests.

---

## 🔧 Features

- 👨‍💼 Employer Registration & Login
- 👤 Job Seeker Registration & Login
- 📄 Job Posting & Management
- 🔎 Job Search with Filters (location, experience, keywords)
- 📝 Resume Upload and Application Tracking
- 📬 Notifications for Job Alerts and Application Status
- 🖥️ Admin Dashboard for Managing Users and Listings

---

## 🧱 Tech Stack

| Layer         | Technology                  |
|---------------|------------------------------|
| Frontend      | HTML5, CSS3, JavaScript      |
| Backend       | PHP or Python (Flask/Django) |
| Database      | MySQL                        |
| Styling       | Bootstrap / Tailwind CSS     |
| Hosting       | XAMPP / Apache / Localhost   |

---

## 🔐 Roles and Permissions

- **Admin**: Manages entire platform, users, and job listings.
- **Employer**: Posts job vacancies, reviews applications.
- **Job Seeker**: Searches for jobs, applies online, and manages profile.

## 🚀 Getting Started

### ✅ Prerequisites

- PHP installed (depending on your backend)
- MySQL / XAMPP
- Code editor (VS Code)

### 🛠️ Installation Steps

```bash
# Clone the repo
git clone https://github.com/your-username/online-job-portal-system.git

# Navigate to the project directory
cd online-job-portal-system

# Set up the database
Import the SQL file into phpMyAdmin or MySQL

# Start the server
Launch using XAMPP or run the backend server (Flask/Django)

# Open in browser
Visit http://localhost:8000 or http://localhost/your-folder-name
